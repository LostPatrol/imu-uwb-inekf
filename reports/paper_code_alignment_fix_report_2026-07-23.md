## 2. 论文依据与最小代码修正

### 2.1 偏置顺序

论文第 4 页式 (27)--(29) 依次定义陀螺偏置 `b_g` 和加计偏置 `b_a`，偏置误差为

```text
zeta = [b_g_hat-b_g, b_a_hat-b_a].
```

原代码却同时存在三套含义：

- 名义传播：`bias[0:3]=b_a`，`bias[3:6]=b_g`；
- 传播矩阵 `A`：第一个偏置块按 `b_g` 使用；
- `P0` 和 `Q`：第一个偏置块又按 `b_a` 设置。

修正版统一为：

```text
bias[0:3] = b_g
bias[3:6] = b_a
P/Q block 4 = gyro bias
P/Q block 5 = accelerometer bias
```

传播矩阵、噪声矩阵、名义传播和更新后的六维偏置因此具有唯一物理含义。

### 2.2 左雅可比零角符号

论文第 3 页式 (11) 的左雅可比一阶项为正号。原代码的一般分支也对应正号，但
`np.isclose(angle,0)` 分支返回 `I-0.5*phi^`，在分支处含义不连续。修正版只把负号改为
正号，仍保留原来的一阶近似，没有额外换用高阶或更高精度公式。

## 6. 耗时说明

两种顺序的完整回放为：

| 顺序 | 第一次 | 第二次 |
|---|---:|---:|
| Original → Fixed | 48.280 s | 36.507 s |
| Fixed → Original | 37.453 s | 40.156 s |

第一次 48.280 s 是明显冷启动。反转顺序后耗时关系改变，说明操作系统预热和运行状态
大于这几行修正的计算差异。本补丁只是交换偏置块和修改一个符号，没有新增矩阵运算，
因此只能得出“没有可识别的固有额外开销”，不能把 36.507 s 对 48.280 s 宣称为加速。
